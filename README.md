# Esha Javed · Portfolio

A static website with no build step.

**Unzip the folder first** (right-click the zip → Extract All). Then double-click `index.html`.
If you open `index.html` straight from inside the zip, the styles won't load.

## Files
- `index.html`: all the page content
- `style.css`: the "Navy, Gold & Rose" theme, layout, animations and phone/tablet/laptop layouts
- `script.js`: loader, typing effect, scroll reveals, card tilt, timeline fill, particles and contact form
- `assets/Esha_Javed_CV.pdf`: the file behind the "Download CV" button

## Easy upgrades
- **Add a photo:** replace the "EJ" circle in the hero (`.mono__core` in `index.html`) with an `<img>`.
- **Add LinkedIn / GitHub links:** add them to the contact cards and the footer.
- **Add project screenshots or a live demo link** to the E-Commerce project section.

## Putting it online for free
Use GitHub Pages (a repository named `<username>.github.io`) or drag the folder onto https://app.netlify.com/drop.
